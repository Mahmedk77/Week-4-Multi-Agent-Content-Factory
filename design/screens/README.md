# design/screens: inspiration only

These are mockups of the Content Factory UI, made for inspiration.

- **We are rebuilding the whole UI from scratch** in the Next.js app, and we will change the design as we go.
- The `.dc.html` files use a custom format (`<x-dc>`, `<sc-if>`, `<dc-import>`). Open them in a browser to see the look, or read them for ideas. Do not copy them into `src/`.
- `base.css` holds the colors, type and component styles used by every mockup (see `UI_DESIGN_SPEC.md` for the token table).
- `canvas.json` is the layout index for the design canvas. Ignore it.

Read `../UI_DESIGN_SPEC.md` first.
